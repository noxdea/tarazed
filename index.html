The terminal, unbundled.

Tarazed supplies the state and protocol core without choosing a renderer, editor model, or interface toolkit.

Faithful screen state

Unicode-aware cells, bounded scrollback, selection, links, colors, and terminal modes.

Chunk-safe parsing

Feed arbitrary byte chunks; incomplete UTF-8 and control sequences wait for the next one.

Real sessions

Drive POSIX PTYs or 64-bit Windows ConPTY with input encoding and shell integration.

Feed the grid.

Use the parser by itself or let a PTY session connect it to a child process.

Ruby
$ bundle add tarazed

screen = Tarazed::Grid.new(
  columns: 80, rows: 24
)
terminal = Tarazed::VT.new(screen)
terminal.feed("\e[32mready\e[0m\r\n")
puts screen.text
